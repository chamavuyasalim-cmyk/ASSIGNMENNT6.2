# Assignment 6.2 — Backgrounds, Borders & Display

Aim: To create three differently styled cards using CSS backgrounds, borders, rounded corners, width, height, and `max-width`, and demonstrate `display: block`, `inline`, and `inline-block`.



## 1. Explanation of CSS properties

| Property                | Purpose                                                                                |
| ----------------------- | -------------------------------------------------------------------------------------- |
| `background-color`      | Gives each card its own background color.                                              |
| `border`                | Creates a visible edge around a card.                                                  |
| `border-radius`         | Rounds the corners of the cards and buttons.                                           |
| `width`                 | Sets the width of an element.                                                          |
| `height`                | Sets the height of an element.                                                         |
| `max-width`             | Prevents an element from growing beyond a specified width.                             |
| `display: block`        | Starts on a new line and normally occupies the available width.                        |
| `display: inline`       | Flows with surrounding text; width and height do not work like they do on block boxes. |
| `display: inline-block` | Flows inline while allowing explicit width and height.                                 |
