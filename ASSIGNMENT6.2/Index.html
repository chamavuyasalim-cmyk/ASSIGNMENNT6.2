CSS Display Properties

The display property controls how an element appears and how it occupies space on a webpage.

1. Display: Block

Block elements start on a new line and normally take up the available width.

Block Element 1 Block Element 2

2. Display: Inline

Inline elements stay within the same line when there is enough space. Width and height do not control their layout in the same way as block boxes.

3. Display: Inline-block

Inline-block elements stay on the same line when space allows, while supporting explicit width and height.
